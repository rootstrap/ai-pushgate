# Generated Code

The TypeScript files in this directory are generated by running:

```sh
pnpm run build:validators
```

Ajv is used at generation time to produce the standalone config validator from
`schemas/pushgate-config-v2.schema.json`. AI review output uses the canonical
Zod contract in `src/ai/review-contract.ts`; the same build command regenerates
`schemas/ai-review-output-v1.schema.json` from that contract for docs and future
native structured-output providers.
